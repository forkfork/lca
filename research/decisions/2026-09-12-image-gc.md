# Managed image retention

LCA now provides `lca gc` (preview) and `lca gc --apply` (cleanup). Remote entry
points schedule a detached host-side check after successful backgrounding or on
foreground attachment, at most once per 24 hours. This is opportunistic maintenance,
not a daemon. Ordinary local sessions never invoke it. Missing configuration,
missing AWS CLI and unavailable/expired credentials are nonfatal skips before
mutation. GC uses only Python's standard library; local-only installs do not need
remote WebSocket packages to run the no-op path.

The config explicitly identifies the managed image and validated rollback. GC
keeps default/rollback, nonterminated VM users, in-progress builds and versions
newer than the prepared default. Candidates are deactivated and rechecked before
deletion. AWS supports disabling new launches by marking versions inactive:
[image activation](https://docs.aws.amazon.com/lambda/latest/dg/microvms-images.html).
Deletion is confirmed by DELETED state or a resource-not-found response after the
delete request. Failures after mutation remain visible; inactive candidates may
require inspection. A local lock prevents overlapping collectors using the same
config; operators must not concurrently reactivate retired versions.

Validation covered preview, retention, pagination, a launch racing deactivation,
config changes, ownership rejection, absent config/credentials/dependencies,
daily cooldown and detached scheduling. The full Lua suite and 47 Python MicroVM
tests passed. The installed launcher also successfully skipped an absent config
from outside the checkout. No application image rebuild was needed.

The live cleanup removed image versions 1.0–6.0. AWS inventory then showed only
7.0 and 8.0, both successful and active, with the user's VM still suspended on
7.0. Preview, apply log and verification are retained privately under
`~/.local/state/lca/maintenance/20260912-image-gc/`. Automatic cleanup is enabled
for this explicitly managed image. No VMs, S3 objects, project data or recovery
files were deleted.
